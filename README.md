# Catalog Studio

لوحة لإدارة كتالوجات منتجات متعددة البراندات. تحفظ البراندات والمنتجات على Neon PostgreSQL، وتحفظ الشعارات وصور المنتجات على Cloudinary.

## التشغيل

شغّل:

    npm install
    npm run dev

انسخ ملف env.example إلى env.local ثم أضف قيم DATABASE_URL وCLOUDINARY_CLOUD_NAME وCLOUDINARY_API_KEY وCLOUDINARY_API_SECRET.

لا تضع القيم الحقيقية في Git أو في متغيرات تبدأ بـ NEXT_PUBLIC_.

## الوظائف

- براندات متعددة، مع الاسم العربي والإنجليزي والشعار.
- رفع الشعار وصور المنتجات إلى Cloudinary بالسحب والإفلات.
- صفحة منتج قابلة للتحرير، مع عدة أحجام أو أوزان وأسعار لكل صفحة.
- استيراد Excel مع معاينة جدولية وتعديل وحذف الصفوف قبل حفظها.
- تخزين المنتجات وإعدادات التصميم على Neon.
- تصدير جميع صفحات البراند النشط إلى PDF.

الجداول تُنشأ تلقائيًا عند أول طلب API ناجح، لذلك لا توجد خطوة migration يدوية مطلوبة للتشغيل الأول.
